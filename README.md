# Adzril Ilham Ramadhan — Official Portfolio Website

Website portofolio resmi **Adzril Ilham Ramadhan** (`adzrililham`), mahasiswa Rekayasa Perangkat Lunak di Universitas Pendidikan Indonesia (UPI). Website ini dirancang sebagai platform showcase interaktif untuk memamerkan kompetensi teknis, rekayasa sistem, dan proyek pengembangan perangkat lunak.

🌐 **Live Website**: [https://adzrililham.vercel.app/](https://adzrililham.vercel.app/)

---

## 🧭 Struktur & Isi Website

Website ini menggunakan konsep alur cerita vertikal (*story-driven flow*) yang terbagi menjadi 6 seksi utama:

1. **01 — About Me (Hero Section)**
   - Perkenalan profil profesional, status ketersediaan magang (*Available for Internship*), ringkasan kompetensi utama, tautan profil sosial (GitHub, LinkedIn, Instagram), serta tombol navigasi cepat (CTA).

2. **02 — Area of Expertise (Core Competencies)**
   - Showcase 6 pilar keahlian teknis dengan tata letak Bento Grid modern:
     - *Full-Stack Web Development* (Pengembangan web end-to-end responsif).
     - *Database & Data Modeling* (Skema relasional, SQL, dan normalisasi basis data).
     - *Object-Oriented Programming* (Prinsip SOLID, clean code, dan arsitektur modular).
     - *Data Analytics & Processing* (Analisis data dan aplikasi visualisasi berbasis Python & Streamlit).
     - *UI/UX Design & Prototyping* (Wireframing dan perancangan antarmuka pengguna di Figma).
     - *Cross-Functional Collaboration & Git Workflow* (Branching strategy, sprint, dan kolaborasi tim).

3. **03 — Tech Stack & Workflow**
   - Visualisasi diagram sirkuit interaktif yang menghubungkan avatar pusat dengan **19 teknologi**:
     - *Languages*: TypeScript, JavaScript, Python, PHP, Java, C++, R, SQL.
     - *Frameworks & Libraries*: React, Laravel, Tailwind CSS, Streamlit.
     - *Tools & Platforms*: Git, GitHub, VS Code, Postman, MySQL, NetBeans, RStudio, Figma.
   - Dilengkapi animasi pulsa aliran data SVG dan tooltip arah cerdas untuk setiap teknologi.

4. **04 — Featured Projects**
   - Katalog studi kasus proyek rekayasa perangkat lunak dengan fitur interaktif *Morphing Dialog*:
     - **LaporJurnal**: Platform integritas jurnal ilmiah (Python 3.12, Streamlit Web GUI, CLI terpadu, Service-Oriented Architecture, dan penyimpanan atomic CSV).
     - **CleanWash**: Marketplace on-demand laundry berbasis web (Laravel 11, Tailwind CSS, MySQL, Payment Gateway).
     - **Smart Parking System**: Sistem manajemen parkir desktop berbasis Java OOP dan visualisasi layout.
     - **ToDoo**: Aplikasi manajemen produktivitas harian berbasis React, TypeScript, dan persistensi lokal.
   - Setiap kartu menampilkan rincian arsitektur, tech stack, dan galeri tangkapan layar antarmuka.

5. **05 — Education & Experience Pipeline**
   - **Education**: Riwayat akademik di Rekayasa Perangkat Lunak UPI beserta daftar mata kuliah relevan (*Data Structures, Algorithms, OOP, Database Systems*).
   - **Interconnected Pipeline**: Conveyor *auto-scroll* horizontal berisi riwayat pengalaman organisasi (Advokasi HIMA RPL UPI) dan berbagai proyek rekayasa sistem. Dapat di-hover untuk pause atau di-drag/swipe secara bebas.

6. **06 — Let's Connect (Footer & Contact)**
   - Informasi kontak langsung, lokasi, dan formulir pengiriman pesan aman yang terhubung langsung ke email melalui integrasi Web3Forms API dengan proteksi anti-spam *honeypot*.

## 🛠️ Teknologi yang Digunakan

### Frontend & Core
- **React 19**: Library inti untuk antarmuka pengguna berbasis komponen.
- **TypeScript**: Static typing untuk keandalan dan skalabilitas kode.
- **Vite 8**: Tooling build dan dev server modern berkecepatan tinggi.

### Styling & Design System
- **Tailwind CSS v4**: Engine styling utilitas CSS-first modern dengan variabel tema kustom (`@theme`).
- **Base UI & Radix UI Primitives**: Primitives unstyled yang aksesibel untuk komponen interaktif.
- **Lucide React**: Koleksi ikon antarmuka berbasis vektor yang ringan.

### Animasi & Interaktivitas
- **GSAP 3 (GreenSock)**: 
  - *ScrollTrigger*: Mengontrol efek pinning, scroll scrubbing, dan section snapping.
  - *ScrollToPlugin*: Mengatur transisi perpindahan antar-seksi yang mulus saat menu navigasi diklik.
- **Motion**: Menggerakkan elemen UI, morphing modal dialog, dan micro-interaction pada tombol.

### Integrasi Layanan Eksternal
- **Web3Forms API**: Layanan pengiriman pesan formulir kontak langsung ke email tanpa perlu backend server khusus.

### Optimasi Search Engine & AI (SEO, AEO, GEO)
- **JSON-LD Schema.org**: Data terstruktur (`Person`, `WebSite`, `ProfilePage`) untuk Knowledge Graph Google.
- **OpenGraph & Twitter Cards**: Tampilan preview kartu saat tautan dibagikan di media sosial.
- **AEO / GEO Crawlers**: Pengaturan `robots.txt`, `sitemap.xml`, dan `llms.txt` agar profil dan proyek dapat dirayapi secara optimal oleh search engine AI (ChatGPT, Perplexity, Claude).
